# 자원예약 상태 판정식 (2026-08-27 개정)

## 두 축
| 축 | SSOT | 단위 | 결정하는 것 |
|---|---|---|---|
| 점유 | `occupied_until` (DB compute_occupancy = EXCLUDE 값) | 시각 | 타인이 이 개체를 예약할 수 있는가 |
| 반납 기한 | `return_due` | KST 날짜 | 연체인가 |

## 예약 1건 — `bookingDisplayStatus(b, now)`
| 상태 | 판정 (status='confirmed' 대상, today = KST 날짜) |
|---|---|
| 취소 | status='cancelled' |
| 반납완료 | returned_at IS NOT NULL |
| 연체 | return_due < today AND 미반납 |
| 예정 | now < start_at |
| 사용중 | 그 외 (start_at ≤ now, return_due ≥ today, 미반납) — 점유 끝 여부 무관 |

## 개체 — `deriveItemStatus(item, bookings, now)`
| 상태 | 판정 |
|---|---|
| 점검중/폐기 | items.status |
| 사용중 | 지금 점유 중인 예약 있음 (start_at ≤ now < occupied_until) |
| 연체 | 점유 중 예약 없고 연체 예약 있음 |
| 예약가능 | 그 외 — 사용중 예약이라도 점유 끝난 개체는 타인 예약 가능 |

## 표시처 (전부 SSOT 함수만 사용)
ResourcePage(카드) · TimelineView(헤더=개체, 블록 색=예약) · CalendarView(점유일=occupied_until 날짜, 연체일=반납일 익일~오늘) · BookingModal 칩(resourceApi.loadOverdue = return_due<오늘) · DetailModal · MyResourceBookings · AdminPanel

## 사용중 기간 변경 (모달 edit)
사용일·시작 잠금(START_LOCKED) / 종료 = 현재 이후 슬롯 + 현재값 유지(PAST_END) / 반납일 ≥ 오늘(PAST_RETURN_DUE). 사용일이 지난 복수일 건은 종료도 잠김.
