# 자원예약 상태 판정식 (2026-08-27 확정)

## 원칙
실물 점유 = 시작 후 ~ 관리자 [반납 확인]. 시각·반납일과 무관하게 반납 확인 전엔 무조건 점유.
반납일(KST 날짜)이 지나도록 점유 중이면 연체.

| 개념 | SSOT | 의미 |
|---|---|---|
| 점유 `isOccupying` | `confirmed && 미반납 && start_at ≤ now` | 실물이 예약자에게 있음 (상한 없음) |
| 연체 `isResourceOverdue` | 점유 중 `&& return_due < today(KST)` | |
| `occupied_until` (DB) | `반납일 19:00 KST`, 반납 확인 시 `GREATEST(start_at, returned_at)` | EXCLUDE·예약 모달 칩의 "타인 예약 가능 범위". 표시 판정엔 쓰지 않음 |

## 예약 1건 — `bookingDisplayStatus(b, now)`
| 상태 | 판정 |
|---|---|
| 취소 | status='cancelled' |
| 반납완료 | returned_at IS NOT NULL |
| 연체 | start_at ≤ now AND return_due < today AND 미반납 |
| 예정 | now < start_at |
| 사용중 | start_at ≤ now AND return_due ≥ today AND 미반납 |

## 개체 — `deriveItemStatus` (카드·타임라인 헤더)
홀더 = 점유 중 건 가운데 가장 먼저 시작한 것(실물을 쥔 사람).
점검중/폐기(items.status) → 홀더 연체 → 홀더 사용중 → 예약가능.

## 타임라인·캘린더 띠
사용 블록 = 사용시간(예정 파랑 / 사용중 분홍 / 연체 빨강 / 반납완료 회색) ·
점유 띠 = 사용시간 뒤 ~ 반납일(반납 확인됐으면 반납 시각까지) ·
연체 빗금 = 반납일 익일 ~ 오늘.

## 사용중 기간 변경 (모달 edit)
사용일·시작 잠금(START_LOCKED) / 종료 = 현재 이후 슬롯 + 현재값 유지(PAST_END) / 반납일 ≥ 오늘(PAST_RETURN_DUE).
